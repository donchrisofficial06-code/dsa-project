# DSA CLA-2: Student Record Search System

**Language:** C  
**Structures:** Binary Search Tree (BST), AVL Tree, Hash Table (Linear Probing)  
**Sample dataset:** 40 student records

## Run
```bash
gcc -Wall -Wextra -std=c11 main.c -o student_search
./student_search
```
Windows:
```bash
gcc -Wall -Wextra -std=c11 main.c -o student_search.exe
student_search.exe
```

Enter a student ID at the interactive prompt; enter `0` to exit.

## Included
- `main.c` — complete implementation of all three structures
- `DATASET.csv` — 40 sample student records
- `REPORT.md` — assignment report template, methodology, complexity and viva questions
- `SAMPLE_RUN_OUTPUT.txt` — output from compiling and running the included code
- `Makefile` — optional build shortcut

**Academic note:** The records are sample data. Run the program yourself, use the values printed by your run in your report, and take your own screenshots. Do not submit fabricated measurements or screenshots.
